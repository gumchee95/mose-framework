# Project Management Core & Operations

Use this skill to structure projects, manage timelines, and ensure operational quality.

## Core Methodologies

### 1. Planning & Scheduling
- **Gantt Charts**: Dependency mapping, critical path analysis.
- **Resource Allocation**: Leveling resources across multiple projects.

### 2. Agile & Scrum
- **Sprint Rituals**: Planning, Daily Standups, Retrospectives.
- **Backlog Grooming**: Prioritization via MoSCoW method.

### 3. Vendor & Procurement
- **Vetting**: Scoring vendors on reliability, quality, and price.
- **SLA Management**: Tracking performance against contracts.
